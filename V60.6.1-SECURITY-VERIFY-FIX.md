# Singh Academy V60.6.1 — security + verify fix

- Removed `nodemon` from backend development dependencies and switched development startup to Node 22 built-in `node --watch`, reducing the dev-only dependency attack surface.
- Pinned Mongoose to `8.24.1`, which is on the patched Mongoose 8 line for the 2026 sanitizeFilter/prototype-pollution advisories.
- Replaced stale hard-coded regression assertions (`V60.5` / `V60.6`) with package-version-derived assertions so the same verify failure does not recur on every patch release.
- Updated package, health, backend startup, Client Admin footer and certificate producer metadata to `60.6.1`.
- No database migration or schema reset is required for this patch.

After install, run both audits:

```powershell
npm --prefix backend audit
npm --prefix backend audit --omit=dev
npm --prefix frontend audit
```

Do not use `npm audit fix --force`.
