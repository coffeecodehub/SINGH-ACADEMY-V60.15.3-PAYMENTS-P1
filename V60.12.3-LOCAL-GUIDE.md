# Singh Academy V60.12.3 — focused guest-observer correction

## Why this patch exists

The supplied V60.12.2 log reports **42/44 browser tests passed**. Both failures
are in `ui-tests/helpers/signed-out-page.ts`, not the payment fixture heading:

1. The helper selected the landing-page branch from a one-time `page.url()`
   read. While it waited for that header, the page moved to
   `/login?next=%2Fteam`. A login page intentionally has no `header.nav`.
2. The unqualified CSS selector matched two header nodes, one marked ready and
   one not ready. The log does not establish whether both were visible; do not
   assume a real duplicate rendering bug is harmless or definitely present.

The new observer re-reads the URL AND current visible guest controls together.
Only a non-rendered header copy is excluded. A persistent second VISIBLE header,
old visible account control, protected URL or wrong hostname still fails.
Direct logout and sibling-tab logout must still end at `/`.
