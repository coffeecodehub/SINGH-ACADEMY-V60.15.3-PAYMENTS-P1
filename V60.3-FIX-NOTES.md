# Singh Academy V60.3 — Enrollment / Course Delete / Membership / Footer Fixes

## Root cause fixed
The live 409 enrollment symptom was consistent with a legacy MongoDB unique index that could make `courseSlug` globally unique. V60.3 treats enrollment identity only as **student + course** (`{ user: 1, courseSlug: 1 }`). Different students can enroll in the same course. The startup repair and V60.3 migration remove every conflicting Enrollment unique rule and the enroll endpoint performs one self-healing retry when an old duplicate-key rule is encountered.

## Course delete
A course with no history is deleted normally. A course that has enrollments, attempts, completions, invoices, or payments is **safely archived** instead of returning 409. It is unpublished and disappears from normal CMS/public course lists, but financial, learner-progress, and certificate history remains intact.

## Access rules
- Free course: any signed-in student can enroll/open it.
- Individual course purchase: access is stored for that student + course only.
- Academy membership: grants the whole currently published course library for the membership term.
- A course published after a membership started is also visible in that member's My Courses and is accessible while the membership remains active.

## Footer contact
The existing footer layout/colors are preserved. The requested Contact heading now groups the configured email, phone, and location. Email uses `mailto:`, phone uses `tel:`, and location opens the configured map URL (or a Google Maps search fallback).

## Payments
Existing Stripe + PayPal checkout, provider verification, webhook, idempotency, payment receipt, invoice, entitlement, and membership fulfillment code is preserved. No live credentials are included in this source package. Configure live credentials only in deployment environment variables.

## Database safety
V60.3 does not seed or reset the database. Existing users, enrollments, subscriptions, payments, invoices, progress, answers, attempts, completions, certificates, reviews, and media are preserved.
