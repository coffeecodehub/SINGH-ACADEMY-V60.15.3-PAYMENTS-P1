# Singh Academy V60.5 Fix Notes

## Implemented in this package

### 1) Individual course purchase invoices in Client Admin
- Added a new **Course purchases** section in the Client Admin sidebar.
- This section lists:
  - student name + email
  - course title
  - invoice number
  - invoice amount / paid amount / outstanding amount
  - payment date
  - access start / expiry dates
  - payment provider reference
  - effective invoice status
- This makes individual course invoices visible in admin, similar to membership tracking.

### 2) Membership access label on course cards
- Public course listing pages now detect when a logged-in student has an active membership.
- For membership-covered courses, the course card now shows:
  - **Membership Access**
  - **Included in your active Academy membership**
- This replaces the visible price on those cards for that student session.

### 3) Certificate redesign
- Updated the certificate PDF design to follow the approved Singh Academy theme more closely:
  - cleaner centered layout
  - larger subtle center watermark
  - balanced shield watermarks
  - same cream/brown theme
  - refined footer blocks
  - professional signature area and seal placement
- The new style is intended to look closer to the provided reference certificate across all courses.
