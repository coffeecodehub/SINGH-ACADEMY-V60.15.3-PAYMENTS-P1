## Implemented changes

- Added a TEST-ONLY browser snapshot reader: current URL, document identity,
  load state, visible headers, login form controls and visible account controls
  are read in one `page.evaluate` call.
- Guest branch is re-selected on EVERY assertion sample, never cached from an
  earlier URL. Login form and landing header cannot be cross-matched.
- Exactly one visible hydrated landing header is required. A non-rendered copy
  is excluded by computed visibility and nonzero bounding box, not `.first()`
  or an arbitrary DOM index. Two visible copies still fail.
- Navigation listeners attach BEFORE the user's Back/Refresh/other-tab logout
  action. Pending main-document requests block a stale ready observation.
- Two consecutive coherent samples must have the same URL/document identity
  and navigation epoch; a transition resets the candidate.
- Only an evaluation context replaced by navigation is re-observed. Actual
  click/reload errors, closed pages and unrelated JavaScript errors propagate.
- Existing five-second assertion deadline retained. No failing test skipped,
  expectation timeout increased, account state cleared to fake logout, or
  production redirect changed. Direct/sibling logout still requires `/`.
- Original 44 browser cases retained, four observer cases added (48 declared).
- Added TypeScript declarations for the new `.mjs` helper; the application uses
  `allowJs:false` and must not rely on implicit-any imports.
- Version metadata 60.12.2 -> 60.12.3 only in application files.
