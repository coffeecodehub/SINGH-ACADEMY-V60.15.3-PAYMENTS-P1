# Singh Academy V60.13.1 — responsive image fixture correction

## What failed, and what this update changes

The supplied V60.13 log reports 853 passing backend tests, a successful TypeScript/Next production build and zero reported audit vulnerabilities. In the browser suite 52 of 53 cases passed. The failed case checks `.courseVisualCard img` and receives `naturalWidth: 0`.

V60.13's synthetic media handler returned a **1x1 PNG for every responsive width**, including URLs described as `480w` and `720w`. `naturalWidth` is density-corrected; it is not always the encoded bitmap's physical width. In the executed Chromium diagnostic the old image decoded and fired `load`, but a 480w descriptor at 1200px viewport made its reported natural dimensions round to zero. The 1x1 fixture also has an invalid IDAT checksum; Chromium tolerated it in this diagnostic, so that checksum is not claimed as the observed browser failure's cause.

V60.13.1 uses a bounded, deterministic PNG producer for **240, 480, 720, 1080 and 1600 actual pixels**, matching the requested descriptor. Original/fallback responses use 1600px. The browser test still requires a decoded image, a positive natural width and a grid-sized selected URL. It additionally checks the physical bitmap dimensions, Team decoding, and a return visit to Courses. No production photograph is replaced by these test images.
