# Singh Academy V34

- Fixed Client Admin/Super Admin course-builder permission mismatch.
- Client Admin is now course-management focused.
- Client Admin can create, edit, delete and preview courses, modules and lessons.
- Course builder supports theory, uploaded video, optional external video, PDF/document, quiz, assignment, journal/reflection and resources.
- Upload endpoints are available to both authorized admin roles for course management.
- Image fields use local file upload and immediate browser preview; image input accepts common browser-selectable image formats.
- Super Admin retains full website/content control.
- Students listing remains filtered to student accounts only.

Security note: server-side role checks remain active. Client Admin cannot edit non-course Super Admin content.
