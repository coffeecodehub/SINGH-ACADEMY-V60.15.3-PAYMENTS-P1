# Singh Academy V35
- Strict portal-isolated authentication: student, client admin, and super admin logins cannot cross-login.
- Client Admin remains Courses-only.
- Super Admin retains full CMS controls; Resources removed from menu.
- Student login notifications are recorded for admin operations.
- Course model supports free, one-time, subscription, and membership access modes.
- Upload URLs are generated from the active backend host instead of hard-coded localhost.
- Upload API accepts common media/document files without image-dimension restrictions.
- Footer/social configuration is Super Admin-only; team social accounts are not part of Team profiles.
- Course builder retains Module -> Lesson -> theory/video/PDF/quiz/assignment/journal structure.
