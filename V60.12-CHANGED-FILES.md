# Singh Academy V60.12.0 — changed files

Base: supplied V60.11.1. This is a targeted patch; production auth/CSRF/session policy, provider SDK verification/atomic fulfillment, media player, public CSS/footer structure and certificate generator/assets are unchanged. Only application version text changes in backend startup/health and the admin footer.

## Application behavior

- `frontend/app/courses/[slug]/page.tsx`: hydrated single-flight start, current owner/course cancellation guard, free-route prefetch and busy-until-navigation feedback.
- `frontend/app/checkout/page.tsx`: owner/product-scoped pending retry identity, no ambiguous provider/option switch, response identity validation, same-key read-only recovery, scoped response generation and restored-page behavior.
- `frontend/app/checkout/return/page.tsx`: validate the requested order, no false failed-payment declaration from a browser cancel flag, cleanup only exact settled retry metadata.
- `frontend/lib/checkoutSafety.ts`: validated non-financial attempt metadata helpers; never stores card data or grants.

## Browser/test infrastructure

- Fixed `.next-ui-tests` / test TypeScript output, owned runner lock/process cleanup, production-mode fixture build before tests. Normal standalone build stays unchanged.
- Original exact URL, logout, free-start timeout and hydration assertions retained. Certificate no-reload assertion now measures document requests/time origin/marker, not ambiguous frame events.
- Seventeen synthetic payment browser cases; eleven HTTP tests of the synthetic API; thirty controlled workflow tests.
- `npm run verify:release` runs full local gates once, stops on failure, and writes an actual results report. It is not a real provider-payment/inbox proof.
