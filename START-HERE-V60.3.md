# Start Here — Singh Academy V60.3

1. Copy your existing working `backend/.env` into this version. Never commit it.
2. Install dependencies on a working network: `npm run install:all`.
3. Run the database repair once: `npm run migrate:v60.3`.
4. Run release verification: `npm run verify` (after lockfiles have been generated by install).
5. Start backend: `npm run dev:backend`.
6. Confirm `http://localhost:5000/api/health` returns version `60.3`.
7. Start frontend in another terminal: `npm run dev:frontend`.
8. Test with two different student accounts enrolling in the same free course.
9. Test a membership account and verify every published course appears in My Courses.
10. Test Admin > Courses > Delete on a course with history: it should disappear without 409 while history remains preserved.

## Stripe / PayPal deployment
Set `ONLINE_PAYMENTS_ENABLED=true`, the production `FRONTEND_URL`, and `PAYMENT_WEBHOOK_BASE_URL`. For Stripe configure `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET`. For PayPal configure `PAYPAL_MODE=live`, `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_WEBHOOK_ID` and optional `PAYPAL_MERCHANT_ID`. In production both providers must use live credentials; do not mix sandbox/test with live.

Before accepting real payments run `npm run payments:check` from the project root after deployment environment variables are configured.
