# V60.5 Verification Fix

The previous V60.5 package failed `npm run verify` because three regression tests still asserted V60.4-era behavior:

1. Client Admin navigation was expected to contain only Students / Subscriptions / Forms / Reviews, so the intentional new Course Purchases section failed the assertion.
2. The certificate PDF implementation was checksum-locked and therefore rejected the intentional certificate redesign.
3. The workspace-version test still required V60.4.

These stale assertions are updated in this package. New V60.5 regression coverage was added for the requested behavior.

Target local sequence:

```powershell
npm run install:all
npm --prefix backend run preflight
npm run migrate:v60.4
npm --prefix backend test
npm run verify
npm run payments:check
```

Use Node 22.x as required by the project engines.
