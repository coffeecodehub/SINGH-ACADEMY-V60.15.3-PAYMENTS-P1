# V60.11 — Changed files and integration notes

## How to use

The complete project ZIP is the preferred update. The PATCH ZIP contains full versions of the changed/new code files plus unchanged integration entry points requested by the user. Apply only to V60.10, preserve your private `.env` and reviewed lockfiles, then run every verification gate. The `.patch` is a human-readable unified source diff, not a substitute for checking the base version.

### Requested code mapping

- `frontend/components/SiteHeader.tsx`: same idle layout, hydration-stable auth values from the provider; centralized sign-out.
- `frontend/app/login/page.tsx`: safe target, single credential request, explicit Back destination and credential-boundary navigation.
- `frontend/app/home/page.tsx`: **unchanged**; no extra competing redirect added here. The root/auth entry redirect belongs to `frontend/lib/server/pageSession.ts` and `LandingAuthGate`.
- `frontend/middleware.ts`: **unchanged**; still performs server session enforcement and overwrites untrusted bootstrap headers. Its `pageSession` implementation is updated.
- Auth helpers/provider/access gate/cookie API: listed below. These changes must be installed together.
- Payments: existing Express API retained. No second server-action gateway or NextAuth migration. Read-only `GET /api/payments/checkout-status` is the new recovery route.
- `frontend/app/styles.css`: original CSS retained as prefix; only appended feedback/player-state/footer rules. No new UI framework dependency.
- All certificate renderer/artwork files unchanged; already-issued PDFs untouched.
