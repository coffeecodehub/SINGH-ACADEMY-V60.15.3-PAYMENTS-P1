# Singh Academy V60.1 bug-fix notes

- Fixed `/favicon.ico` 404 by adding a real multi-size favicon generated from the existing approved Singh Academy logo.
- Fixed `/api/health` reporting the stale V57 version; it now reports V60.
- Hardened enrollment startup: the backend now safely removes the two known legacy over-restrictive unique Enrollment indexes (`courseSlug`-only or `user`-only) and ensures the intended unique `{user, courseSlug}` index exists before serving requests.
- The enrollment endpoint remains idempotent: an already-enrolled student receives success rather than a duplicate-enrollment conflict.
- Existing users, payments, enrollments, progress, certificates, course content, and approved public UI are preserved.

## Why the browser showed 409
The V60 route itself does not intentionally return 409 for an existing enrollment. A 409 can be produced by MongoDB duplicate-key handling when an old unique Enrollment index is still present, or by an older backend still running on port 5000. V60.1 repairs the legacy index at startup. If port 5000 is occupied by an older server, stop that old backend and start this package.
