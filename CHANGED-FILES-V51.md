# V51 requested changes

V51 intentionally changes only the requested areas on top of V50.

- Course resume persistence and previous/next module navigation.
- Try Again feedback presentation in the learner while keeping prior attempt history.
- Stable Team category ordering: Founder, Core Team, Faculty, Board.
- Professional Contact page and optional contact topic storage.
- Course-authoring UI removes prerequisites, skills, tools and credit-hours fields.
- Quiz authoring adds explicit MCQ and MSQ answer types; MSQ is persisted/validated as multiple selections.
- Admin section Back navigation, attractive confirmation dialogs, and success feedback; curriculum add/delete/duplicate/order/module updates also confirm.
- Requested landing photo focus and real middle-card image using existing Academy imagery.
- Requested exact SA shield logo used as the default site logo.
- Requested certificate visual treatment using the same SA shield, watermark pattern, brown/cream frame, signature area, verification link and gold seal.
- Additive `migrate:v51` command for new optional schema/index support.

No student payment, subscription, certificate-review, direct Stripe/PayPal, or existing Try Again history was removed by this update.
