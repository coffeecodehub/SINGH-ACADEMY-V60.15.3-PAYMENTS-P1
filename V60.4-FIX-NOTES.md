# Singh Academy V60.4 — Fix notes

- Preserved the approved public UI baseline; only the user-requested footer Contact placement and busy-state feedback are intentional visible changes.
- Footer Contact is now a standalone column beside Explore, Learn and Account; email, telephone and location are clickable. Existing Contact navigation remains.
- Lesson editor now exposes an Embed block and accepts broad HTTPS video/social links. Native embeds cover YouTube, Vimeo, TikTok, Instagram, Facebook, TED, Dailymotion, Loom, Streamable, Wistia, Vidyard and Twitch; other HTTPS providers remain usable as safe external links.
- Lower lesson content-block embeds lazy-load; the primary lesson video remains eager.
- Shared/in-flight caching removes duplicate public `/content/site` requests; public team/events/site responses also use short cache headers.
- Major user-facing async buttons now expose `aria-busy`, disable duplicate clicks and show an existing-label + spinner busy state without changing idle UI.
- Fresh MongoDB Atlas databases no longer crash enrollment index repair when the `enrollments` collection does not exist yet.
- Enrollment uniqueness remains exactly `user + courseSlug`; no course is globally unique across students.
- Added V60.4 migration and health/version markers.
- Added `DEPLOYMENT_STAGE=review`: public client review can use Stripe test + PayPal sandbox while live credentials are explicitly blocked. Live production still rejects sandbox credentials.
- Updated Next.js to 15.5.27 and added a scoped PostCSS 8.5.23 override for the current audited maintenance line.
- GitHub verification can generate missing nested lockfiles for the CI run, while using `npm ci` whenever reviewed lockfiles are committed. Release guidance still asks maintainers to commit the generated backend/frontend lockfiles.
