# V60.6 verification fix

The V60.6 certificate theme intentionally changed the certificate producer marker from V60.5 to V60.6. Two regression assertions were still pinned to the older V60.5 producer string, so the full verification stopped even though the rest of the suite and payment configuration passed.

This package updates:
- root/backend/frontend version metadata to `60.6.0`
- `/api/health` version to `60.6`
- backend startup log to V60.6
- Client Admin visible version label to V60.6
- certificate regression assertions to V60.6

No database migration is required for this verification-only version alignment. Continue using `npm run migrate:v60.4` for the latest schema/index migration.
